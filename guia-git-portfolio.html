Guia rapida: subir tu portfolio a GitHub con Git

Proyecto: mi-resume-web

1) Ir a la carpeta del proyecto

cd C:\Users\josel\Desktop\mi-resume-web

2) Inicializar Git

git init

3) Configurar usuario (solo la primera vez en tu PC)

git config --global user.name "Jose Perez Maysonet"
git config --global user.email "perezjose210100@gmail.com"

4) Ver estado y agregar archivos

git status
git add .

5) Hacer commit

git commit -m "Create modern resume portfolio with React, Tailwind and animations"

6) Crear repositorio en GitHub

  • Entra a GitHub y crea un repo nuevo (por ejemplo: mi-resume-web).
  • No marques README si ya tienes proyecto local.

7) Conectar remoto y subir

Reemplaza TU_USUARIO y TU_REPO:

git branch -M main
git remote add origin https://github.com/TU_USUARIO/TU_REPO.git
git push -u origin main

8) Para futuras actualizaciones

git add .
git commit -m "Describe aqui el cambio"
git push

Errores comunes

  • not a git repository: estas en la carpeta incorrecta o falta git init.
  • remote origin already exists: usa git remote set-url origin URL.
  • failed to push: haz git pull --rebase origin main y vuelve a subir.
Consejo profesional: no es hacerlo perfecto sin ayuda; es entender el flujo y poder repetirlo con seguridad.
